## About this index

GitHub has no folder or nested group for repositories. Classification uses a controlled topic vocabulary:

- `domain-*` - subject area: `frontend`, `backend`, `ai-ml`, `agent`, `tooling`, `learning`, `apps`, `misc`
- `src-*` - provenance: `src-original`, `src-fork`, `src-study-copy`
- `state-archived` - read-only repositories

This page lists public repositories only. Repository ordering here is manual; the repositories tab remains sorted by last push.
